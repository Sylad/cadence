### Changed

- `cadence perf` also reads the state files of `cadence run` (L795, issue #69, [docs/perf.md](docs/perf.md#lots-made-by-cadence-run-l795)): a week of lots made by run no longer leaves every line `n/d` but `livrés`. Correction passes (red gates handed back to the session, runs launched after a non-compliant review), right the first time, wall time per run and per lot, cost per delivered lot (`cout_usd`) and UX sessions (plan verdict) are filled; a lot made both by a wave and by runs is counted once. A new line `sources des lots rendus` (and `sources` in `--json`) tells which source each rendered lot came from. Tokens per lot and the review share stay `n/d` for run-only lots: a run state holds no token counts.
