Dans le panneau des lots (`/hud lots`), la section « ordre des projets » affiche pour chaque projet la même barre d'avancement que le bandeau du bas : lots clos sur total, colorée selon la part faite (rouge, orange, vert), avec les lots en cours et le `+N cette semaine`. Quand le bandeau est trop chargé pour montrer tous les projets, on lit l'avancement de chacun dans le panneau, sans faire défiler.

Les noms des projets sont alignés pour que les barres le soient aussi. Le glisser-déposer et **Alt**+↑ / **Alt**+↓ pour ranger les projets fonctionnent comme avant. Avec une version de cadence trop ancienne pour donner l'avancement, la ligne garde son `N lots non clos`.
