### Changed

- The tests CI (`.github/workflows/tests.yml`) plays one run per burst of pushes and the suite once per Node version (L834, D-33, [docs/releasing.md](docs/releasing.md)): a push cancels the run of the same branch still in progress (the tip's run plays the cancelled commits too; `publish.yml` is never cancelled), and the last step checks the package with `npm publish --dry-run --ignore-scripts` instead of replaying `prepublishOnly` (typecheck, ratchet and the whole suite a second time). Estimated: about 55 min a run before, about 30 after; a burst of n pushes costs one run instead of n. The suite inside the publish lifecycle is still played by `cadence release` (fresh clone, smoke test of the installed package) and by `publish.yml`.
