The README now has a short section, **Lead several projects in 10 minutes**, and a new page, `docs/quickstart.md`, that takes you from
install to the first wave: Node and Claude Code, the parent folder, `raf init` in each project, the tour, `/cadence:lead`, the first wave.
Its last table lists the usual stops (no Node, `EACCES` on `npm install -g`, no git identity, Claude Code not logged in) with the fix for each.

Reporting a problem or asking for something is easier too: the repository now offers two issue forms, **Bug** and **Request**.
The bug form asks for `cadence --version`, the steps and what was printed.
