### Fixed

- A lot declared `config: true` in the plan may write its own changelog fragment, and only that one (L770, [docs/qualite.md](docs/qualite.md)): since L679 every lot writes `changelog.d/<lot>.md`, but the config-lot rule of `scripts/qualite.mjs` (L586) only accepted `CHANGELOG.md`, so the quality ratchet refused the fragment. The first fix accepted all of `changelog.d/`; the fragment of another lot, `changelog.d/README.md` or any other file there is now refused by name, on the lot's branch as at the integration gate (where a commit writes only the fragment of a lot its scope cites). A lot id with `/` writes `changelog.d/<id>.md` or the same name with `/` as `__`.
- The tests of the `cadence-hud` mod get a 30 s wall-clock delay instead of the kit's 5 s (L770, `plugins/cadence-hud/tests/kit.ts`): they run on a simulated clock, and under the load of a full gate a different 0.5–3 s test went past 5 s on each run. A test that sets its own `timeoutMs` keeps it; no assertion changed.
