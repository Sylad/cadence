### Fixed

- `cadence news` (L807, [docs/news.md](docs/news.md)): inside a `cadence run` session, the entries folder is the run's worktree (`CADENCE_CLONE`) even when the command is launched from the main tree of the same repository. On 22-11 an entry skeleton left in the main tree made the integration of a run refuse. `--dir` still wins, and outside a run nothing changes.
- `cadence run`: the state file of a run is written atomically (temporary file, then rename). A concurrent reader, such as `cadence run --liste` or another run of the same repository, could read an empty file and fail with « Unexpected end of JSON input ».
