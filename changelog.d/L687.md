### Added

- The `cadence-hud` band shows each `cadence run` and its state (L687, D-1, [docs/cadence-hud.md](docs/cadence-hud.md)): one aligned line per run,
  `▶ run cadence:L687  en cours  opus 12 min · $1.20  <request>`, live runs first (playing, or waiting for the quota with its resume time), then the ones
  integrated less than 30 min ago and those waiting for a gesture (question, red gate, conflict, interrupted…) for 12 h. In the lots panel, a lot a live run
  plays reads `⟳ run` (`⏸ run en quota`) instead of `◌ en sommeil`.

### Changed

- While the lots panel is open, the band no longer repeats what it shows: the progress of the plans and the bench lines leave the band and come back when
  the panel closes (L687). The slots line counts the runs without naming them (`runs cadence run : 1 · …`): each has its own line.

### Fixed

- After a drag in the lots panel, « à commiter » is said only when the moved file is in a git repository: a parent folder of projects that is not one now
  reads `priority: du cadence.yaml est modifiée (dossier hors dépôt git : rien à commiter)` (L687).
