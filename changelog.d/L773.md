### Fixed

- `cadence run --fond` writes one journal per run, named after the run id (`../.cadence-run/fond-<id>.log`) instead of the launch second (L773, issue #64 of the pro account, [docs/v2/2026-11-09-cadence-run.md](docs/v2/2026-11-09-cadence-run.md)): two runs launched in the same second from the same repository shared `fond-<AAAAMMJJHHMMSS>.log` and interleaved their lines. The launcher now picks the run id (second and its pid), creates the journal exclusively and hands the id to the run (`CADENCE_RUN_ID`, not passed on to its `claude` sessions); the launch line names the id, and the run state cites its journal, which `--liste` and `--purger` read. Test: `v2/test/run-fond-journal-l773.test.ts` launches two real `--fond` runs in the same second and checks two distinct journals.
