### Added

- Every v2 bench report (`~/bench-cadence/rapports/`, short, mechanical, micro, noise and sequence passages) now records its environment, in the `.md` header and as `environnement` in the `.json`: the Claude Code version (`claude --version` at launch, plus the version each session announced), the exact model id of each arm as its sessions announced it (`claude-opus-5-5`, never the `bras.yaml` alias alone), other billed models, the max context of each model, and the tracked settings that change cost or behaviour (effort, `CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES`, `CLAUDE_CODE_*` and `ANTHROPIC_*` model settings, `effortLevel`/`fastMode`/`env` of the user and arm settings files). The first line after the title compares with the previous report (`⚠ Environnement différent de <run> : Claude Code : 2.1.293 → 2.1.325 ; alias fable : … → …`), and the ⚠ line is also printed on the output of every passage, sequences included; other billed models (subagents) are written but never compared, since whether an arm starts a subagent depends on the session, not the environment; `cadence2 bench comparer <a> <b>` compares any two reports (L742, D-23, [docs/v2/banc.md](docs/v2/banc.md#environnement-dun-passage-l742)). Claude Code had gone from 2.1.293 to 2.1.325 on Big-Blue, and the `fable` alias had pointed to Fable 5.2 since 09-11, without any report showing it.
