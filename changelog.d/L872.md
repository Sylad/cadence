### Fixed

- Bench leak rule (L872): a bare `/*` or `/**` outside a recursive command now counts as `/`, which is allowed. On the 25-11 benches, all 68 « / » leaks on both arms (mostly arm A) were JS, TS or Java comment markers in a python heredoc or a `sed` expression, with no read of the root. `grep -r x /*`, `ls /*/…` and a `Glob` on `/**/x` still count. The bench hook shares the rule (`cheminsCites`, `v2/hooks/lecture.mjs`; [docs/v2/banc.md](docs/v2/banc.md)).
