### Fixed

- Bench (L817, follow-up of L808): the candidate arm's hook and the leak detector now see the search of 22-11 in its most plausible form, with one shared rule in `v2/hooks/lecture.mjs`. `Grep` and recursive commands (`find`, `rg`, `du`, `grep -r`, `ls -R`…) read everything under their directories, so `find ~ -name playwright` is refused and counted; a glob that can name a forbidden zone (`ls ~/proj*`, `ls ~/*/developpeur`) is a certain leak; a bare `cd` goes to `~`, and from a directory that contains a zone a bare name is a path (`cd $HOME; ls projects`); `ls ~` alone is only to be checked. Quoted `echo`/`printf` arguments are ignored only when their output goes to a file or to a filter that does not read it (`tee`, `sort`, `head`…), never when `sh`, `while read`, `xargs` or `parallel` read them, nor inside `$(…)` or a subshell. The argument of a `grep`/`rg` option (`-m 1`, `-A 3`, `-g "*.md"`) is no longer taken for the pattern: `grep -m 1 <path> notes.md` judges the path. See [docs/v2/banc.md](docs/v2/banc.md).
