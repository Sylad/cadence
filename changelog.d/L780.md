### Fixed

- Gate ↔ CI parity no longer flags a false gap when an environment variable in front of the command is computed by a command substitution (L780, issue #65, [docs/orchestrate-gate.md](docs/orchestrate-gate.md)): `PATH="$(ls -d "$HOME"/.nvm/versions/node/v$(cat .nvmrc)*/bin | sort -V | tail -1):$PATH" CI=1 npx ng test --no-watch` now covers the CI's `npx ng test --no-watch`. Nested quotes, `$(…)`, `$((…))` and backticks are read as one shell word, and a `|` or a parenthesis inside them no longer splits the command; a real gap is still flagged.
