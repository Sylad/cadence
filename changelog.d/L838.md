### Added

- `run.fastGate` in `cadence.yaml`: a fast gate for `cadence run` (L838, D-33, [docs/config.md](docs/config.md#fast-gate-during-a-run-runfastgate)). During the run, the tests step plays only the tests touched by the lot's diff (the touched files, the tests declared by `bounds`, the tests that name a touched page), with a command declared per project (`command` with `{files}`, `dir`, `full` patterns) or derived from a `vitest run` gate with `fastGate: true`. The selection falls back to the full suite, and says why, when it is uncertain: a deleted or moved file, a `full` file or `cadence.yaml` touched, a file outside `dir`, no file touched, or a linked command that finds no test. No verdict is noted after a fast gate, so the full suite is still played once, at the delivery gate (`cadence verify --gate`). Each gate of a run keeps its scope, result and duration in the run state (`portes[]`); measure on cadence itself in [docs/mesures/porte-rapide-l838.md](docs/mesures/porte-rapide-l838.md).
