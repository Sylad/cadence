### Added

- `cadence mesures <url>`: layout measures of a page in one pass, the « script mode » of the `ux-reviewer` (L839, D-34, [docs/mesures-page.md](docs/mesures-page.md)). At 375, 768, 1024 and 1440 px and in each state asked for (`--etat "<name> → cliquer <selector>"`), it measures the horizontal scroll and the elements that cause it, truncated texts, words cut between two letters, values split from their unit, short labels on two lines, targets under 24 × 24 px, the smallest font and the landmarks with their gutters, and prints figures only, the same finding at several widths on one line. Exit codes: 0 no finding, 1 findings, 2 not verified. The `ux-reviewer` uses it when its brief carries `Mode: script`: no `browser_snapshot`, captures read from disk, one numbers-only script for contrast, focus and motion. The bench that decides whether the mode stays (same review replayed in both modes, known defects found, tokens and tool calls) is ready with its commands in [docs/mesures/ux-mode-script-l839.md](docs/mesures/ux-mode-script-l839.md); `node scripts/banc-ux-script.mjs <url>` measures a reduced case with no model (28 to 35 % of the floor of the current mode on two mockups of the repository, 54 % on a short test page). `scripts/jetons-agents.mjs` now also counts the tool calls of each agent call (`outils N`). A short bench played on 25-11 (the review of the test page by `claude -p`, two trials per arm) compared the current mode, `Mode: script` and the experimental Code Mode of Claude Code: all three find the 7 known defects, and neither mechanism is cheaper than the current mode (Code Mode +26 % cost, script mode +3 % cost and 2.3 times the duration), so neither becomes the default ([docs/etudes/2026-11-25-code-mode-banc-court.md](docs/etudes/2026-11-25-code-mode-banc-court.md)).
