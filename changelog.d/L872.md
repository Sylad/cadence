### Fixed

- Bench leak rule (L872): a JS, TS, Java or CSS comment opener (`/* R14`, `/** Text`, `/**` followed by a ` * …` line) quoted as text, in a heredoc body or between quotes, is no longer read as the root. On the 25-11 benches, all 47 calls counted as a « / » leak on both arms were such markers in a python heredoc or a `sed` expression; replayed on their transcripts, the rule finds none. Any other `/*` or `/**` is still read as `/`, refused by the bench hook and counted: a shell argument (`for f in /**`, `echo /* | xargs grep -rl x`, `grep -r x /*`), an interpreter's glob (`bash -c 'cat /**'`, `glob.glob("/**", recursive=True)`), a `Glob` on `/**/x`; nothing is removed when the command names `globstar`, `zsh` or `recursive=True` (`sansCommentaires`, `v2/hooks/lecture.mjs`; [docs/v2/banc.md](docs/v2/banc.md)).
