### Added

- `raf demande` writes the register of requests, `.cadence/demandes/D-<n>.json` (L722, [docs/raf.md](docs/raf.md#a-branch-held-by-a-program-the-pending-plan-l695)): `raf demande` lists the open requests, `raf demande D-3` prints one, `precision "text"` appends a dated précision (the original text is never rewritten), `etat livrée|vérifiée|abandonnée "proof"` changes the state and appends its proof (or the reason of an abandon), `lot L12` attaches a lot. On a branch held by a program the write is queued in the pending plan, like `raf note`.
- At its start, `cadence run` and `cadence verify --gate` name the files the main tree has not committed, the pending plan left out (L722): the run starts from `HEAD` and the gate plays its sha without them, and a file the run also changes makes its integration fail.

### Changed

- `raf review` and `raf ux` on a branch held by a program (`cadence run`, a gate in the main tree) are queued in `.cadence/plan-en-attente.yaml` like `raf add|note|done`, instead of writing the plan of the main tree (L722). `done`, `review` and `ux` from a session of a wave are refused before being queued.
