### Fixed

- The test suites no longer depend on the `CADENCE_*` variables of the session that runs them (L715): `v2/test/bras.test.ts` and `v2/test/passage.test.ts` failed (« expected '[]' to be undefined ») whenever `CADENCE_PIECES`, `CADENCE_CLONE` or `CADENCE_BANC_RACINE` were set, which is the case of any suite run from a `cadence run` session. The setup files (`test/setup-env.ts`, `v2/test/setup-home.ts`) now remove every inherited `CADENCE_*` before each test file (except `CADENCE_TEST_*`, the settings of the suite itself), and a test that reads one sets it itself. The bench's neutral environment no longer passes the guard of a parent `cadence run` session (`CADENCE_CLONE`, `CADENCE_PIECES`, `CADENCE_BANC_RACINE`) to an arm without settings or to the judges. Tests: `test/environnement-isole-l715.test.ts`, `v2/test/environnement-isole-l715.test.ts`, `v2/test/bras.test.ts`, `v2/test/passage.test.ts`.
