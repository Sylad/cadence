### Fixed

- `cadence run` regenerates a project's News data itself (L781, [docs/v2/2026-11-09-cadence-run.md](docs/v2/2026-11-09-cadence-run.md)): the session may not run `cadence`, so a project whose `scripts.news` calls `cadence news build` got its lots integrated with stale News data. When `package.json` declares `scripts.news`, the run plays `npm run news` (then `plan.onWrite.command`) in the worktree before each gate and commits what changed in one commit of the lot; a failing command is handed back to the session like a red gate, and the commit is replayed after a rebase so two runs never conflict on the generated file.
