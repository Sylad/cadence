### Changed

- Every `cadence run` session starts lighter (L705, D-7, [docs/v2/2026-11-09-cadence-run.md](docs/v2/2026-11-09-cadence-run.md)): its `--settings` turns off the user's and project's enabled plugins except `cadence` and `playwright` (`enabledPlugins`, as waves do since L398), the claude.ai account connectors (`disableClaudeAiConnectors`; plugin MCP servers stay) and auto memory (`autoMemoryEnabled: false`). Measured on real `claude -p` sessions launched like a run (Haiku, minimal prompt): first turn 64,844 → 57,653 tokens (−11 %), about $0.12 per lot with `cadence cost` ([measurement](docs/mesures/socle-session-2026-11-11.md#coupes-appliquées-l705-2026-11-12)). The bench keeps its settings.

### Added

- `run.worktreeOutside: true` in `cadence.yaml` puts the run's worktree under `$CADENCE_HOME/run-worktrees/` instead of `../.cadence-run/`, so Claude Code no longer loads the `CLAUDE.md` of the repository's parent folder (−5.3k tokens measured on the first turn). Off by default, per repository: that file can carry safety instructions. State, lock and journal stay in `../.cadence-run/`; a non-boolean value is refused before anything is created.
